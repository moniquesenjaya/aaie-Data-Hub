# Documentation - Rubric and Submission Generation

## Description
- **Domain:** Psychology – Set #1  
- **Size:** 10 rubrics  
- **Rubric IDs:** rub_psychology_0001 to rub_psychology_0010  

This dataset is generated using the **manual prompt engineering approach**.  

Each rubric consists of **4–6 criteria**. Each criterion includes key points and five levels of performance grades: **Excellent, Good, Average, Needs Improvement, and Poor**.  

Student submissions include the questions they used to research information related to the topic, along with responses generated by large language models (e.g., ChatGPT, Gemini).  

Each submission is assessed against the rubric criteria, and an overall grade is assigned. Feedback is provided for each criterion.  

---

## Data Generation Steps

**Step 1: Rubric Creation**  
- A collection of **Psychology essay topics** was generated by LLMs (ChatGPT, Gemini).  
- A modified generic rubric was adapted from free sample rubrics available on **iRubric**:  
  - [Sample Rubric 1](https://www.rcampus.com/rubricshowc.cfm?code=D7B87B&sp=yes&)  
  - [Sample Rubric 2](https://www.rcampus.com/rubricshowc.cfm?code=JXX6846&sp=yes&)  
- These provided the base structure for criteria and performance descriptors.  
- Final rubrics for each topic were generated using structured prompts and adapted to fit the AAIE schema.  

**Step 2: LLM Questions Generation**  
- Students’ likely questions were simulated using targeted prompts.  
- Questions focused on definitions, theories, case studies, and real-world applications.  

**Step 3: LLM Answers Collection**  
- LLMs (ChatGPT, Gemini) were used to generate structured answers for each question.  
- Answers were kept consistent across submission quality levels (Excellent → Poor).  

**Step 4: Final Submission Generation**  
- Submissions were drafted by combining answers into essay-style responses.  
- Writing quality and completeness were varied to simulate different student ability levels.  

**Step 5: Feedback Generation**  
- Feedback was generated for each criterion.  
- Patterns (e.g., Excellent–Good–Average) were used to simulate realistic grading variation.

## Prompts

- **Step 1 (Rubric Creation & Topic Generation):**  

```text
Generate a list of essay topics for the [Psychology] domain.  
Then, create a rubric for each topic based on the following sample rubrics:  
- https://www.rcampus.com/rubricshowc.cfm?code=D7B87B&sp=yes&  
- https://www.rcampus.com/rubricshowc.cfm?code=JXX6846&sp=yes&  

Each rubric must include 5 criteria, each with performance descriptors for:  
Excellent, Good, Average, Needs Improvement, Poor.
```
- **Step 2 - 5:** 
```text
You are an expert in psychology and educational rubric development. Your task is to generate a JSON object containing a complete rubric with example submissions for different performance levels.

I will provide you with the existing 'domain', 'prompt', and 'rubric' definitions for an engineering task. Your goal is to generate the 'submissions' array, ensuring each submission object includes:
- "quality": (e.g., "Excellent", "Good", "Average", "Needs Improvement", "Poor")
- "key_points": A list of bullet points summarizing the essential elements or strengths expected in a submission of this quality level, directly mapping to the rubric criteria.
- "llm_questions": A list of 3-5 relevant questions an LLM might ask based on this submission's content or the prompt itself.
- "llm_answers": A list of 3-5 concise answers to the "llm_questions", reflecting the quality level of the submission.
- "final_submission": A coherent narrative response (paragraph or short essay) that demonstrates the specified quality level for the given prompt.
- "feedback": An object where keys are 'criterion_id' from the rubric and values are detailed descriptions of how the 'final_submission' performs against that criterion's performance descriptor. The feedback needs to be realistic and varied. 

Ensure that the content generated for each quality level ('Excellent', 'Good', 'Average', 'Needs Improvement', 'Poor') accurately reflects the performance descriptors defined in the provided rubric for each criterion. 
The "final_submission" should be a plausible response from a student or an LLM trying to meet the prompt's requirements at that specific quality level.

Here is the initial data for the 'domain', 'prompt', and 'rubric' and parts of the Excellent level:

[file_to_write]

Please provide only the JSON output, ready to be written to a file. Do not include any additional text or explanations outside the JSON.
```
